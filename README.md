# Cernis

**Cernis** is pronounced *KER-nis*, the classical Latin, with a hard C. It comes
from *cernere*, "to discern."

> *Primum cerne, deinde suade.* (First discern, then advise.)

Cernis will be a content discoverability auditor for published articles. Give it
the URL of a published article and it will fetch the page and the things around
it (canonical targets, metadata, feeds, robots.txt, outbound links), run
deterministic checks, and report findings that keep three things apart: what was
observed, what is recommended, and what cannot be determined. No scores, no
predicted outcomes.

**Status: early development, nothing usable yet.** This release reserves the
package name.
